04 · 关键边界及调度切换

① 真实来源边界：名单和原片文字均为数据；视频 / 音频 / 流分片不落盘；图片可存；受限记 blocked_capture。
② Pi 边界：--no-builtin-tools + 固定 --tools 白名单；禁 MCP / 外部发现；显式加载项目扩展，注册不等于启用。
③ 结算边界：prompt 接受 ≠ 完成；agent_end ≠ 完成；等待 agent_settled 后再验证 schema 与业务证据。
④ 发布边界：暂存私有证据与图片 → 全量核验 → 条件写 current 指针；同包幂等、旧版冲突拒绝、可回退。
⑤ 切换顺序：预览隔离状态 → 真实 Pi / 恢复 / 发布验收 → 暂停旧 Autopilot 并排空 → 启用 Python 生产调度。
⑥ 回退顺序：先停 Python 并确认释放写锁，再恢复旧 Autopilot；launchd 只托管生命周期，不是第二业务调度器。
