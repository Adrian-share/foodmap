- [视频样例表](data/creators/beijing-samples.csv)：14 条样例，保留原视频链接、发布日期和门店线索，通过 `creator_id` 关联总表。
- [使用与维护说明](data/creators/README.md)：字段定义、筛选方法、去重规则和待补信息。
- [原始候选名单](data/creators/sources/2026-11-11-beijing-candidates.md)：保留来源，方便复核。
