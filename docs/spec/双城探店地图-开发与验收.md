## 首版产品

覆盖北京和上海。复用已验收的高德交互式地图与 MCP。用户输入地铁站、酒店或地标后，两个入口共用同一份门店数据、地点解析和排序逻辑。网页地图显示起点和附近门店，MCP 在 Codex 内返回相同的门店、距离和出处。没有地点时先问用户在哪个酒店、地铁站或地标附近。

首批内容来自已核对的北京十家门店、上海候选门店，以及三位指定 UP 主在两座城市公开发布、能够核对到具体门店的探店视频。[特厨隋坡](https://space.bilibili.com/3546888255048212) · [厨者王波](https://space.bilibili.com/3546728118618546) · [真探唐仁杰](https://space.bilibili.com/544336675)

门店与探店视频分别存储。一家分店对应一个地图点，可关联多位博主或同一博主的多次探店。地图点展示门店、分店地址、直线距离与原视频入口。城市、分店、坐标或原视频存在疑问时，标记为待确认，退出附近排序。若有同名地点，先展示城市、行政区和候选地点，再由用户选定起点。

## 两城 ATDD

| 输入 | 预期起点 | 固定样本前三名 |
| --- | --- | --- |
| 北京王府井地铁站 | 北京市东城区王府井地铁站 | 富春居（北京璞瑄酒店店）1.72 km、泰丰楼 1.92 km、北京宜宾招待所·餐厅 2.82 km |
| 上海豫园地铁站 | 上海市黄浦区豫园地铁站 | 上海老饭店（豫园店）0.31 km、绿波廊酒楼（豫园总店）0.46 km、和平饭店龙凤厅 1.25 km。第三项以酒店点位作为固定样本。 |

- 先用固定地点和门店样本写验收测试，记录失败。网页和 Codex MCP 对同一个起点的前三名顺序、距离及原视频链接一致。距离按直线计算，固定样本误差不超过 0.05 km。
- 在地图从北京切到上海时，旧标记和列表清除。点图钉能打开对应分店及原视频。MCP 用无地点上下文的新会话测试「我附近有什么」，先追问。用户回答「上海豫园地铁站」后返回上海门店。
- 固定样本测试通过后，再用真实地图和 Codex 中的实际 MCP 调用复测。交付自动化结果、两城地图截图及对应的 MCP 调用记录。WorkBuddy 配置沿用上一轮，客户端联调独立记录。
- 固定样本排名用来验收产品行为。导入更多店后，同一输入的实际前三名可能变化，网页和 MCP 仍须对同一版本的数据返回一致结果。
