## Codex 实际调用

固定与实时两种模式各使用三个独立新会话：缺位置会话（两轮）、王府井直接查询、豫园直接查询。总计 6 个会话、8 轮。每个模式：

1. 无位置新会话问“我附近有什么？”：先追问，`tools/call` 0 次、地点解析 0 次，没有默认位置或推荐。
2. 同会话补充“上海豫园地铁站”：1 次真实 MCP 调用，返回正确上海起点与三家结果。
3. 独立王府井和豫园会话：各 1 次真实 MCP 调用，顺序、距离、出处和网页逐字段一致。
4. 每次成功查询实际接收三张 JPEG 图片块，图片哈希与清单一致，回复包含三张 Markdown 原视频封面。

原始调用不是手工编造：`codex-fixture/*.jsonl`、`codex-live/*.jsonl` 为 Codex 的实际事件，`audit.jsonl` 为服务端独立审计，`*.json` 保存命令和事件；`conversations.md` 保存可读对话。汇编见 `Codex-MCP-调用记录.md`。图形客户端与 WorkBuddy 最终渲染未实测。
