## 接入与数据边界

Codex 示例：先 `npm start`，再执行 `codex mcp add beijing_food_map --url http://127.0.0.1:8767/mcp`，开新会话验收。
WorkBuddy 示例是 `config/workbuddy/mcp.json`，传输类型为 `streamableHttp`；替换 `url` 为从客户端可达的 `/mcp` 地址。
本实现默认回环监听，跨机器接入需要另行转发，不能直接复用另一台机器的 127.0.0.1。
WorkBuddy 安装、登录、客户端联调和发布均未进行。

本轮使用固定样本，没有调用高德实时服务。地图链接是既有坐标出处，不代表本次实时解析。
“附近”仅表示十家样本中的最近三家，距离为直线距离；东坝最近一家仍约 8.11 km。
不包括设备定位、IP 定位、账户位置记忆、博主筛选、路线和营业状态确认。
